# 工程结构与恢复机制

LocaleShift 是 Swift Package，使用 SwiftUI／AppKit 构建 macOS 菜单栏应用。主界面不以 root 运行；系统修改与恢复责任分给两个独立服务。

| 模块 | 主要职责 |
| --- | --- |
| `LocaleShiftCore` | 配置、独立默认基准、SQLite 持久化、锁、操作记录、切换／恢复状态机、离线推荐与双时钟 |
| `LocaleShiftSystem` | CFPreferences、原生系统读取、签名约束 XPC、SMAppService、系统能力门禁和进程身份 |
| `LocaleShiftApp` | 菜单栏、管理窗口、首次准备、差异预览与退出确认 |
| `LocaleShiftUserAgent` | 当前用户语言／地区写入、会话检查与有限恢复 |
| `LocaleShiftTimezoneService` | root 级固定时区调用、机器级占用、读回核验和独立时区恢复 |

## 配置和恢复基准

“系统默认配置”保存完整首选语言顺序、地区和固定时区。它必须先于工作切换确认，不因切换目标、重新启动界面或重新打开引导而自动覆盖。

工作配置保存一个目标首选语言、地区和时区。应用时将目标语言置于首位，保留其他原有语言的相对顺序并去重。恢复时回到基准保存的完整语言列表。

每次操作先记录实际状态和恢复责任，再执行写入，最后独立读回核验。失败、中断或外部改动时保留相应记录；不能核验成功就不报告恢复完成。

## 权限与生命周期

生产信任模型要求三个进程由同一个可信 Apple Team ID 签名。本机测试模式通过显式编译启用，使用管理员安装的 root 所有固定副本与代码哈希校验；两种模式的服务和数据分开。

系统能力未验收、后台不可用或存在冲突时阻止新切换。正常退出先恢复并核验；界面进程关闭不等于后台恢复责任被删除。重启后继续保留工作配置的功能目前关闭。

## 影响范围

语言与地区作用于当前用户，固定时区作用于整台机器。只修改这三项；不修改绝对时间、网络校时、自动时区开关、输入源、浏览器独立偏好或终端环境变量。

默认模式记录位于当前用户 `~/Library/Application Support/LocaleShift`，机器级恢复记录位于 `/Library/Application Support/LocaleShift`。本机测试模式使用独立的 `LocaleShiftLocalDevelopment` 目录。诊断由用户主动导出到本地。

## 离线资源

地区和语言推荐由系统与随包资源生成。IANA 候选、首都时区和地点别名在构建时打包；不需要网络查询用户 IP。数据来源见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
