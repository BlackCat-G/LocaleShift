# 验证与兼容性

这是公开源码的验证范围说明，不把临时探针、模拟测试或编译成功合并为“所有产品功能通过”。历史原始日志和本机安装记录不随仓库发布。

## 当前能力门禁

`Sources/LocaleShiftSystem/Capabilities.swift` 只为 **macOS 27.0.1 / arm64** 开放语言、地区、固定时区修改及后台恢复。其他系统组合保持修改关闭。

最低编译目标是 macOS 13。该值只约束编译，不代表从 macOS 13 到所有更新版本都已兼容；即使其他版本构建通过，也不会因此自动获得系统修改能力。

## 已有本机观察

以下为开发期间记录的单机结果，不能推广为所有环境承诺：

- 临时原生探针完成语言顺序、地区、固定时区修改与恢复；包括纽约、东京及加德满都的非整小时时区。
- 临时探针观察过进程中断、真实睡眠唤醒、正常注销与正常重启后的恢复路径。
- 本机测试模式的应用完成纽约／东京实际切换、整套系统默认恢复，以及专用界面进程被终止后的后台恢复。
- 窗口修订在本机正式安装副本中取得菜单栏打开、三指拖移和 ⌘W 关闭的用户反馈。
- 针对持续读盘、侧边栏点击及切换结果提示做过本机修订和检查。

原始证据由维护者留在本地；公开仓库提供可运行源码、隔离测试与构建步骤。新增能力需要对应版本的独立实机验证。

## 可以重复执行的检查

```sh
./scripts/test.sh
python3 scripts/build_app.py --configuration release --output build/validation/LocaleShift.app
codesign --verify --deep --strict build/validation/LocaleShift.app
```

自动化测试覆盖持久化、唯一性、语言顺序、恢复状态、并发、时差和资源等行为，不调用真实系统设置写入。静态签名校验不等同于可信分发签名、公证或后台服务实测。GitHub Actions 的结果也不等同于实际切换验收。

## 尚未完成

- 更广泛的 macOS 版本、Intel 及多用户环境的系统功能验收。
- 正式签名／公证包的服务通信、权限撤销及完整生命周期验收。
- 正式发布版安装、更新、回退与卸载流程。
- 系统崩溃、突然断电及相关磁盘异常后的完整实机矩阵。
- 重启后继续保持工作配置；当前该能力关闭。

贡献新的系统支持时，记录完整系统版本、架构、构建方式、实际切换与读回、完整恢复、后台服务状态和测试结束后的状态；请不要直接去掉系统能力门禁。
